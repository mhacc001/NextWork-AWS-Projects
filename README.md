# NextWork AWS Projects

Hands-on AWS project writeups completed through NextWork's AWS Beginners Challenge and related tracks. Each project includes step-by-step documentation, screenshots, and key takeaways.

## Projects

| Project | Key Concepts |
|---|---|
| [Cloud Security with AWS IAM](./Cloud-Security-with-AWS-IAM) | IAM Policies, IAM User Groups, EC2, Resource Tagging, Account Aliases, IAM Policy Simulator |
| [Encrypt Data with AWS KMS](./Encrypt-Data-with-AWS-KMS) | AWS KMS, Envelope Encryption, S3, Key Policies |
| [Threat Detection with GuardDuty](./Threat-Detection-with-GuardDuty) | Amazon GuardDuty, CloudFormation, EC2, S3, CloudShell, SQL Injection, Command Injection |

## About

These projects are part of a self-directed cloud security learning path, building hands-on AWS skills across identity and access management, encryption, threat detection, secrets management, and continuous security monitoring.
